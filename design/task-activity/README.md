# 流光 π — Piora 任务状态动效

设计样稿，供「凝思求解中」前的运行标记使用。保留 Piora 原有 π 轮廓、深蓝底和紫青渐变。

- π 主体保持正立，轻微呼吸缩放（±1.5%），不整枚旋转、不忽明忽暗。
- 一颗青色光点沿外圈顺时针巡游，短尾迹从紫色过渡到青色。
- π 横梁与两条笔画错峰出现短促流光，避免整幅图同时闪烁。
- 每轮 2.4 秒，48 帧、20 fps，无限循环。
- 推荐状态栏尺寸 24 × 24px；预览同时展示浅色和深色背景。

## 文件

- `preview.gif`：放大动效与 24px 状态栏的浅色/深色设计预览，不是应用实测截图。
- `piora-thinking.gif`：96 × 96px 透明 GIF，可按目标尺寸显示。
- `piora-thinking-24.gif`：24 × 24px 原尺寸透明 GIF。
- `piora-thinking.webp`：96 × 96px 无损透明动画，保留更平滑的半透明边缘。
- `piora-thinking.svg`：可缩放的 CSS 动画版本，内联使用时支持 `prefers-reduced-motion` 静态降级，已验证偏好切换后停止。
- `preview.png`、`piora-thinking.png`：静态预览帧。
- `render.mjs`：读取项目原始 SVG 并导出动画的可复现脚本。运行 `node design/task-activity/render.mjs`。
- `verification.json`：帧数、尺寸、时长、透明度与循环检查。

## 接入建议

运行时替换当前的小圆点，预留固定 24px 空间，不做按钮，不响应点击。完成/停止/失败后停止动画，继续使用各自的静态状态标记。网页接入优先使用内联 SVG 或 WebP；GIF 可直接用于设计评审。减少动态效果偏好应使用静态 PNG/内联 SVG，GIF 本身无法响应系统偏好；外链 SVG 的动态偏好切换不可依赖图片缓存刷新。

这是基于现有矢量图标制作的动效素材，尚未接入 TaskDuration，也未更改应用图标。
