## 开发约束

使用 Piora 的真实浅色／深色主题变量与现有 AliIcon 线性图标。浅色主按钮近黑底白字，深色反转；蓝色只用于选中与焦点。正文 14px、元信息 12px，信息密度由间距控制。设计图中的画布边距和软阴影用于展示，桌面窗口内部不重复模拟窗口边框。

管理页默认列表宽 380 DIP、行高 64 DIP；快捷窗保持 760×540 DIP、行高 56 DIP。暂存默认 360×420 DIP，文字／文件／图片卡片分别为 84／72／128 DIP，列表可滚动。尺寸以实际可访问性和小窗口约束为准；生成图不是逐像素尺寸测量来源。

来源和时间分别用弹出筛选；回收站、收录、归档和清理收进「更多操作」。常用动作仍可通过快捷键和条目菜单使用。普通浏览时减少常驻勾选框；悬停、键盘焦点与多选状态显示勾选框。窄管理页在列表和详情之间前进／返回，保留列表位置。

归档与数据操作沿用实际桌面桥接接口。设计图里的示例记录不写入产品数据。没有新增 OCR、AI、云同步或顺序粘贴。

`lib/clipboard-v2-browser.test.mjs` 渲染实际组件，使用从 `app/globals.css` 读取的生产主题变量。用虚构样例数据生成 `.verification/clipboard-v3/` 中的管理页、快捷窗、展开预览、多选、错误和暂存浅深色截图；这些是实现截图，与上面的生成设计图区分保存。

本次保存的实现截图：[管理页](./manager-implemented-v3.png)、[深色快捷窗](./quick-implemented-v3.png)、[屏幕暂存](./shelf-implemented-v3.png)。

后续交互补充：[未保存编辑提示的实现截图](./unsaved-edits-implemented-v3.png)。切换记录、筛选或隐藏预览时，可继续编辑、放弃修改或保存后继续；保存失败不会丢失输入。管理页还会恢复浏览位置，旧历史的前后分页保持可见记录不跳动。

内容详情补充字符／行数、尺寸／容量与主动打开链接。混合类型多选提供可恢复的分组入口：[混合分组实现截图](./mixed-groups-implemented-v3.png)。快捷窗展开预览采用更紧凑的间距；完整格式与正文保存策略不因预览缩短而改变。

验证结果：根目录与桌面 TypeScript 检查、桌面编译、变更文件 lint、浏览器回归均通过。原生 Electron 窗口与受限 PNG／缩略图读取、非授权窗口 IPC 拒绝也通过，报告复制到 `.verification/clipboard-v3/native-ui-report.json`。此次视觉复核未重新执行系统剪贴板写入和跨应用粘贴，因此该报告的 nativePaste / nativeCapture 为 not requested。

原生 Electron 验证由 `scripts/verify-clipboard-native.mjs` 运行。更广泛的跨应用、安装包和性能验收仍按 `docs/clipboard-v2-implementation.md` 跟踪，不因本次视觉调整而自动视为完成。
