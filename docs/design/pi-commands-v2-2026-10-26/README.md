# Piora 命令交互 · 第二版

基于用户对第一版卡片过多的反馈，保留交互规则，重新调整视觉层级：

- 执行状态直接排在对话中，移除卡片底色、圆角和内嵌容器。
- 成功详情默认收起，只保留状态、摘要与轻量文字操作。
- 输入区以单条分隔线界定，Skill 与 query 在同一个输入区提交。
- 命令菜单缩窄为紧凑列表，图标去除底板。
- 附件改为文字与图标，错误日志和扩展问题直接展开排列。

`index.html` 是独立交互原型，`overview.html` 是全部状态图。所有执行均为模拟，不连接 Pi。第一版保留在相邻的 `pi-commands-2026-10-26` 文件夹。

运行 `node docs/design/pi-commands-v2-2026-10-26/render.mjs` 重新生成图片并验证交互。使用 Playwright 与 Edge，无需 Next.js 构建。
