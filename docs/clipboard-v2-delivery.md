# 随身仓剪贴板交付说明

本次按 uTools 官方「剪贴板」的核心使用方式完成改造，并按三张 v3 设计图实现管理页、快捷窗口和屏幕暂存。

Windows 可运行目录包：`X:\release-workspaces\clipboard-2D11wt\desktop\release\win-unpacked\Piora.exe`。保留同目录资源一起使用。最终打包和运行检查通过，已包含最后的来源列表读取改动；未覆盖安装当前应用。

## 使用

在随身仓打开「剪贴板」，首次使用点击「开启记录」。默认 Ctrl+Alt+V 唤起快捷窗口；输入关键词查找，Enter 粘贴，Shift+Enter 纯文本粘贴。快捷键可在设置中修改。需要反复使用的记录可以加入屏幕暂存。

历史支持文字、富文本、图片、文件及文件夹；可收藏、备注、编辑副本、多选合并、拖出或另存。管理页提供来源／时间筛选、回收站和归档导入导出。应用加密备份包含剪贴板历史。
