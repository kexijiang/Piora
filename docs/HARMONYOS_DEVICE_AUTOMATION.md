# HarmonyOS / OpenHarmony 设备指南

当前桌面工作台使用普通会话；已通过 HDC 连接的设备可直接操作，不再添加应用范围或单次动作审批。投屏不会自动解锁。未知设备保持实验性状态，不能把软件测试通过视为所有手机已验证。
