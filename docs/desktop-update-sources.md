# 桌面更新来源

Piora Windows x64 安装版固定从 GitHub 检查更新，不再提供 GitHub/内源切换。启动和手动检查、下载前复查、安装前复查均使用相同的 GitHub 发布列表；旧的 update-source.json 与 release-audience.json 记录不再决定 Piora 的更新来源和候选渠道。

Beta 和正式安装版均检查较新的 Beta、正式版，以语义版本号选择最高的已发布版本。同一基础版本的正式版高于 Beta；更高基础版本的 Beta 可以作为正式版的更新。版本更低或相等时不更新，不自动降级。Alpha、开发运行模式、便携版及不支持的平台仍需使用对应的 Windows 安装版。

## 发布元数据

- GitHub Atom/XML 发布列表包含 /releases/tag/<版本标签> 链接，标签如 v0.5.10-beta.25 或 v0.5.10。
- 每个标签目录提供品牌对应 beta.yml/latest.yml（使用 APP_BRAND.updateChannels）、Windows x64 NSIS 安装包和 blockmap。
- YAML 必须保留该品牌的准确版本、单个相对安装包文件名、SHA-512、大小和完整发布说明；不能指向另一品牌、外部地址或 web-installer packages。
- 下载继续交给 electron-updater 执行 SHA-512 校验。

缺少更新元数据的未完成发布会被跳过；网络错误会报告失败。更新元数据继续校验准确版本、Windows x64 NSIS 安装包文件名、SHA-512、大小及完整发布说明。

设置保留当前版本、GitHub 最新版本、检查更新和失败重试。定时静默更新开关及本地时间设置保持可选，任务运行或存在未保存编辑时延后安装。Beta 安装版同样支持这些操作。

Alpha、开发版和便携版的不可用提示与版本信息分行排列，窄屏和较大字体下允许换行。禁用原因由桌面 updater 提供，并在定时设置 IPC 中复用。

## 验证边界
