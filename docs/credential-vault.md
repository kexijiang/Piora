# 本地凭据库

桌面端在「设置 → 数据 → 本地凭据库」创建主密码（至少 12 位），添加登录页 URL、用户名、密码、名称、分组及备注。解锁有效期为 10 分钟，重启后保持锁定。界面默认遮盖用户名与密码，编辑已有账户时密码留空表示保留。

数据独立保存于 Electron userData 的 `credential-vault.enc`，由 Electron `safeStorage` 系统加密保护（Windows 为 DPAPI）。不提供明文导出、服务器 API 或模型工具；系统加密不可用或 Linux 使用 `basic_text` 后端时拒绝启用。主密码用于解锁验证及备份验证，本地文件由系统账户密钥保护。忘记主密码不能通过界面恢复。

导出需要重新输入当前主密码，再选择文件。备份采用 scrypt 派生密钥及 AES-256-GCM 加密；导入需要先解锁凭据库，再输入备份导出时的密码。导入全部验证成功后追加条目，不覆盖原条目；重名/重复站点会形成多个候选，需要用户选择。普通会话/设置导出不包含此独立文件。

## 填写

自动填写默认关闭；开启后，在加载完成的内置浏览器页面或凭据配置变更时检查唯一匹配项。关闭时只显示匹配提示，可在浏览器登录菜单中选择账户，或在凭据库点击「填入当前浏览器」。晚于页面加载才出现的动态表单可使用手动填写。后台 Playwright 浏览器与其他应用输入框不接入凭据库。

匹配采用精确 HTTPS origin 与路径，不支持通配域名；拒绝明文 HTTP、IP 地址、带账户信息或 Punycode 的域名。查询串不参与匹配。只有一个可见密码框、一个可见用户名框、同源 POST 表单时才允许填写。支付、验证码、新密码、安全设置或不能识别的表单不填写。用户录入的准确站点是信任边界；这不是在线钓鱼检测服务。

不自动点击登录或提交表单。填写前暂停会话的浏览器智能体，隔离页面截图、执行脚本及 CDP 读取，并丢弃此前未返回的读取结果。保护跨导航持续，避免站点复制值后被读取。完成登录后，点击「关闭受保护页面并恢复」，关闭该会话的受保护标签，随后可打开新页复用网站自己的登录状态。审计仅记录条目名称、站点与时间，不记录密码或表单内容。

系统加密保护静态文件，不构成对同一系统用户的任意本机程序、已授权全权限 Shell 或目标网站本身的隔离。网站会接收到填写的凭据；请仅为自己信任的站点保存账户。自动填写不向会话历史、模型请求或应用日志发送用户名和密码。

## 验证边界

- 存储测试使用注入的 AES 加密夹具，验证磁盘无明文、错误密码、篡改备份、原子导入、匹配与失败保留原数据。
- IPC/浏览器管理器测试使用 Electron 夹具，验证不可信发送方拒绝和迟到读取丢弃。
- 浏览器测试在真实 Chromium/Edge 中验证登录表单填写、不会提交及危险表单拒绝。
- Windows 原生测试使用无窗口 Electron 和真实 `safeStorage`，验证加密落盘、重建实例解锁与读取；其他平台跳过此项。
- 原生保存/打开对话框、真实网站登录及发布安装包仍需单独实机验收。
