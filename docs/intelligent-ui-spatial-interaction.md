# Intelligent UI 三维交互与视图状态

2026-11-02 | 已实现并有局部验证，第三阶段尚未完成

当前运行器支持对象拾取、轨道旋转、缩放、键盘操作和独立镜头保存。普通新生成通过[按窗口环境协商](intelligent-ui-window-environment.md)判断 WebGL 是否可用，并关联原始提交；服务端不会因为本机开发测试通过就替所有窗口声明可用。整体设计仍以 [v3.8](intelligent-ui-phase3-design-v3.8.md) 为准。

## 计划和投影协议

在 `scene3d` viewport 中可分别声明 `picking:true`、`cameraControls:true`，省略表示沿用原有静态场景行为；这些字段不适用于 Canvas。采用新交互的计划选择 `mini-app-1.4`，旧计划保持原来的版本选择。

启用拾取时，每个 mesh 必须有稳定 `id` 和可读 `label`；场景投影必须给出 `selected:objectId|null`，非空对象必须仍在当前网格集合中。可信渲染器进行射线求交，并提供原生对象选择框供键盘使用。任务的 `reduce` 接收 `{type:"scene-pick",id:viewportId,object:objectId|null}`；模型把选择写入显式任务状态，再由同一状态生成选中对象及解释。禁止根据屏幕坐标猜测三维命中。

宿主为渲染帧维护最近 32 份对象身份记录。持续存在的对象可接受队列中的旧帧点击；删除再创建同名对象后，旧点击被丢弃。清空选择只接受当前帧。实例恢复和任务复位会使旧身份失效。

新程序发布前对初始场景最多抽样 32 个选择/清空事件，按声明视口分配，并包含每个视口的最后一个对象。每次从同一初始检查点独立试运行，普通事件仍受 8ms 限额约束；发布结果不携带试验选择。错误指出视口、对象及状态字段，帮助修正过窄的选中状态枚举。这是有限抽样，不能保证后续新增对象或全部路径；读取历史保存记录不追加这组探测。

自定义 mesh 的 positions 是 xyz 顶点数组。无 indices 时每 9 个数构成一个三角形，不能直接提供四边形边界；四个共面顶点可用 indices:[0,1,2,0,2,3] 表示两个三角形。诊断包含具体场景、mesh 索引和顶点数量；不自动补点、删点或改写模型几何。

启用镜头控制时，场景 `camera` 是初始或显式复位镜头。用户可拖动、滚轮缩放，或使用箭头、加减号、Home 和宿主按钮。拖动结束不会被当作点击选择。平移、自动旋转和阻尼动画未开放。

普通重投影不会覆盖用户镜头。程序若需要“重新观察”，应在任务状态中递增 `cameraRevision` 并把它放入场景投影；不能在每次投影或普通输入变化时递增。宿主的整体复位仍沿用当前参数重新初始化任务，同时清除用户镜头；视图内的镜头复位只改变观察角度。

## 组合结构与局部关节

当当前窗口的 `sceneGroups` 能力可用时，`scene3d` 视口可声明 `groups:true`，计划采用 `mini-app-1.5`。场景的可选 `groups` 数组由 `{id,parent?,position,rotation,scale}` 组成；网格的可选 `parent` 引用同场景组。位置、旋转及缩放均相对父节点，根节点相对场景。旋转为弧度、XYZ 欧拉顺序；局部变换按缩放、旋转、平移应用。

组合结构把整体姿态放在共同父组上，子部件只保留局部位置，避免每个部件围绕自身中心转动而脱离主体。关节组放在支点，子部件位置从支点计算；嵌套组可表达多个关节。分组不会自动修复初始几何间隙、比例或解释。

全帧最多 64 个组，最多 8 层组嵌套；组和网格 ID 不得重复，父节点必须存在且无循环。声明顺序无关。没有 `groups:true` 的旧视口不接受新字段，未使用新能力的计划仍按原版本编译。模型提示、工具接纳和发布都沿用同一能力检查。

渲染器先移除发生变化的父关系，再建立新关系，避免反转父子关系时短暂产生环。删除、重新归属和恢复使用稳定的网格 ID；组本身不增加可选对象，射线与键盘选择仍针对网格。用户镜头与关节/主体角度分开保存。

## 保存及恢复

检查点在原有 `inputs/state/rng/tick` 之外增加可选 `view:{version:1,cameras:{viewportId:{reset,camera}}}`。任务状态与镜头状态分开；生成的生命周期函数拿不到镜头状态，也不能直接写入它。服务端重新投影时保留并验证这部分宿主数据，不接受未知视口或不匹配的字段。镜头复位版本改变后，仅移除受影响的旧镜头。

保存前先冻结原生输入、刷新待发送镜头、释放拖动，再等待操作队列清空。恢复时重新创建渲染器并应用镜头，保持暂停。真实浏览器测试同时检查恢复后的数据和画面像素；生产状态服务另测文件、回执和重复请求。

镜头距离限于 0.05 至 10000，向量分量限于正负 10000，视场角为 15 至 90 度；数值边缘允许浮点舍入误差。现有三视口、200 网格、50000 三角形、128 KiB 帧与执行预算继续生效。相机事件最多每秒 30 次，连续同视口事件可合并；实际任务事件保持顺序。

后续上下文包含保存的选中对象 ID/名称、镜头及其来源。`saved-user-view` 是观察视角，不代表模型对象自身的姿态或几何关系；任务参数与投影摘要仍需一起解释。

WebGL 上下文丢失会停止本实例、保留最后检查点并显示可恢复提示。开发测试通过真实 `WEBGL_lose_context` 扩展触发丢失；这不等于真实显卡故障、原生最小化或多窗口恢复已经验收。
