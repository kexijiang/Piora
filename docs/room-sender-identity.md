# 内置群聊发送者身份

用户发送与智能体会话绑定是两个不同身份。内置群的本机用户 ID 保存在 `<agentDir>/piora/room-local-user.json`，名称取当前操作系统账号；同一 Piora 配置重启后沿用同一 ID。HTTP 入参中的协调者 sessionId 仍用于原有群操作校验，不再写成用户的发送者 ID。

智能体消息在保存时从群成员记录取得名称和 memberId，并保留执行 sessionId。换绑后的历史消息仍按稳定 memberId 或迁移前的会话映射归属。模型指令、最近群消息、团队任务和补充指令均包含结构化身份；转交同时提供直接发送者和可追溯的原始请求者。调用方传入的显示名称不能覆盖已落盘消息的归属。

旧用户消息没有可靠身份来源时标为 `legacy_unknown`，不把协调者 ID 反推为真实用户。`local_account` 只表示本机 Piora 用户配置，不是企业账号登录、工号认证或多用户服务的身份认证。多人共用同一 Piora 配置时仍属于同一本机身份；要按企业工号授权，需要另行接入认证与服务端授权策略。

姓名和消息正文均不授予权限。现有工具权限、独立审查和人工确认仍是执行边界；任何正文中自称管理员或伪造发送者 JSON 的内容都不能更改已保存的发送者元数据。
