# Intelligent UI 数值比较

2026-11-02。Plan2 增量能力，第三阶段尚未完成。

组件可直接表达 `lt`、`lte`、`gt`、`gte`，分别表示小于、小于等于、大于、大于等于。每个操作必须恰有两个数值操作数，结果为布尔值；支持命名派生值和内联表达式。`equals` 保留原有严格标量相等语义。

例如，用户已经给定门槛和规则时，可以使用：

```json
{
  "id": "eligible",
  "op": "gte",
  "args": [{ "input": "amount" }, { "input": "threshold" }]
}
```

再由 `if` 计算条件结果。`if` 的两个分支仍须返回相同标量类型，不能把数字与空字符串混用；动态说明应分开组织文字与数值。比较能力不会补齐未知费率、门槛或业务规则，也不会把数字字符串转成数值。

## 编译和兼容性

新比较写法由编译器确定性转换成已有的 `min/max`、`equals` 与惰性 `if`。持久化仍为现有 Surface2 表达式，加载和运行不需要新增可执行代码。使用比较的 Plan2 记录 compilerVersion 2.7.0；不使用比较的原有计划继续保留 2.5.0，只有转换声明的计划仍为 2.6.0。Plan1 不接受新运算。

转换后的运算完整计入 256 项计算、12 层表达式和 4096 个展开节点的现有预算。多出来的字段、错误参数数量、非数值输入、循环与未声明引用仍拒绝；不能把相等边界误当成严格大小关系。

## 可以自然地试

- “奶茶每杯 18 元，满 100 减 20，每单只能减一次。先按 6 杯算，我想改改杯数，看实付多少钱、平均每杯多少钱。”
- “买东西满 200 包邮，不到就加 12 块运费。先按 180 块算，我想改改商品金额，看运费和总共要付多少。”
- “室温低于 18 度我觉得冷，超过 26 度觉得热，中间刚好。先按 20 度，给我个能调温度、马上看到提示的小面板。”

重点核对 199/200/201 元、18/26 度等边界；改值后同时看指标与说明，再刷新、追问当前结果。生成成功不是语义正确的证明。模型评估分别记录 Flash 开启和关闭推理，不会自动更改用户设置。
