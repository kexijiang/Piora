# 观察、输入和停止

投屏默认可直接操作，没有额外控制开关。首次点击、滑动、输入或运行测试时自动取得手动租约；仅观看、缩放、截图不会取得租约，也不会自动唤醒或解锁。AI 或另一窗口持有设备时保留旁观，只有点击“停止并接管”才停止所选设备的当前控制者。切换设备、关闭面板和离开页面会释放自己的控制，过期请求不会恢复旧手机的输入。

应用、测试、语音、日志和记录共用一个按需展开的工具抽屉。连接诊断、按键校准与代码检查从设备设置进入；停止入口在底部状态栏，窄面板展开工具时也能使用。

引用绑定设备 epoch、观察 revision 和 30 秒期限；点击前必须重新观察并唯一匹配身份。空树、解析失败、部分树、重复身份和窗口变化不会退回旧坐标。负向断言必须基于有效且覆盖目标窗口的观察。

画面 CSS、视频编码、截图和原生输入是不同坐标系。服务端从真实显示信息和已观察帧签发 geometryId；帧坐标由服务端转换。原生点仍检查实际尺寸。旋转、窗口变化、折叠或停止产生的旧几何不会继续派发；预览断线清除可控制标识。

实体 `key_hold` 是有界 down/interval/up 序列，不等于逻辑 keyEvent 或屏幕 long_press。音量键最长 5 秒、电源键最长 3 秒；触摸保持最长 15 秒，均要求精确时长校准。校准按钮只执行一次；人工确认必须实际看到预期行为和释放。`open_assistant` 只能使用当前机型/系统上已记录、并验证目标控件的助手配置，不能猜唤醒时长。

点击文本动作区分 set、append、clear；要求语义 provider 与精确回读，能力不足明确拒绝。滚动使用方向、单步最大次数与全场景累计 60 次搜索滑动预算，不用不可控的搜索滚动替代。driver_idle 与 bounded_delay 是不同结果。

“停止设备”同步关闭该设备的新写入，再异步清理其资源；全局急停是另一个显式操作。清理超时显示 recovering/uncertain，不能当已松开。断开 USB 后先检查实际按键/触摸是否释放，再处理诊断。面板关闭只关自身画面订阅，不停止其他任务的手机。
