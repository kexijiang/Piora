# 第三阶段：状态服务与预览进展

2026-10-31 | 3B / 3C 实施快照 | 第三阶段尚未完成

## 1. 本轮实现

本轮按设计 v3.1 补充持久状态、读取/保存 API、模型上下文读取与布局预览。实现仍位于专用 worktree，尚未注册小程序生成工具，也没有完成真实聊天中的生成、操作、刷新和追问闭环。下列成果属于基础能力与产品接入进展。

| 工作 | 实际结果 |
| --- | --- |
| 独立持久状态 | 操作检查点与不可变发布日志分开存储。保存输入、JSON state、随机序列、tick、投影结果和版本；不会改写原始工具回执 |
| 并发与幂等 | 保存使用 expectedRevision 与 requestId。重复请求返回原回执；两个旧版本写入只能有一个成功，避免静默覆盖 |
| 分支保护 | 状态绑定分支节点与内容摘要。修改祖先时固定已有子分支继承的状态，新建子分支才继承新值 |
| 服务端投影 | 客户端只能提交检查点；服务器在真实 QuickJS Worker 中重新 project，保存实际文字与图形结果。投影在写锁外运行，提交前重新核对身份、分支、开关与版本 |
| 追问上下文 | 生成协调器读取已提交的操作状态。上下文捕获后发生参数变化，会阻止旧候选创建或发布；原始发布内容保持不变 |
| API | 新增会话作用域 mini-app GET / PUT，支持保存回执查询、跨站拒绝、JSON 大小限制、关闭 Beta 后读取及当前分支核对 |
| 预览 | 新增 React 布局预览组件。只读视口显示占位，不创建 Canvas 或 WebGL 上下文；尚未登记到聊天渲染器 |
| 回收站 | 软删除与恢复保留小程序发布、状态侧车文件；永久清理时一并移除。通用路径层不加载实验模块 |

状态文件按会话限制为 32 MiB、最多 10,000 个分支锚点及 50,000 条保存回执；到达限制时明确拒绝，保留既有内容。相同锚点合并最新状态，回执不按年龄自动删除。上下文读取一次状态文件后复用锁内快照，避免每个小程序反复解析整份文件。

保存服务的 project 校验只证明输入/状态格式与投影一致，不证明每一步都来自真实用户点击，也不授权文件或其他外部动作。前端本机草稿、保存门禁与权限动作尚需后续接入。

### 具体覆盖的状态行为

保存后重新读取能得到新的参数、tick 和服务端计算结果；会话文件与发布日志字节保持不变。原 requestId 重试不重新写入，改变同一 requestId 的内容会被拒绝。并发旧版本请求只允许一个提交。祖先编辑不影响已有后代，历史视图不可借用当前分支写入。

实际 Worker 投影期间切换分支、关闭 Beta 或取消，不会落下迟到状态；合法终态恢复仅执行 project，不强行再走一步。损坏的持久结果读取失败，不作为有效状态。自动标题更新可推进无分叉锚点，且保持原请求幂等。

生成运行时测试进一步核对：保存起始参数 7、计数 37 后，新上下文包含这些已保存值与 stateRevision 1，而不是初始计数 2。测试不调用真实模型，因此没有由此推断 DeepSeek 的选择或生成正确性。

### 首次失败及处理

API 首次测试出现保存冲突应返回 409、实际返回 500。原因是模块隔离加载下 Error 类的构造器身份不同，instanceof 没有识别已知错误。改为核对稳定错误名称与字段，兼容模块重载；保留原 409 断言后复测通过。未删除断言或将失败请求计为成功。

## 3. 验证边界与后续工作

浏览器渲染测试使用真实 Edge、opaque iframe 和实际 Three.js 绘制；本轮增加检查只读预览没有 canvas 节点，根节点 inert。三维回归沿用软件 WebGL 配置，不代表原生 GPU、真实桌面窗口或其他平台验证。

状态和 API 测试使用独立临时会话、真实 SDK 会话文件、写入所有权、磁盘回执与服务器 QuickJS Worker。未访问用户会话或模型凭据。API 入口通过测试直接调用，尚未用真实 Next 开发服务完成端到端保存；React 预览组件已通过类型和 lint 检查，尚未单独完成产品内交互验证。
