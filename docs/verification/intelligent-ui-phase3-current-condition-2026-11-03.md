## 真实桌面中的目标变化

三份新程序均完成 21 项 UI 操作，共 63 项，其中包含 12 次刷新和 3 次原生按钮空格键操作。每步核对杯内数值、步数、画面读数和当前目标文字，再保存；刷新后再次核对。原始生成记录摘要不变，真实追问后检查点和版本不变，清理无错误。

| 轨迹 | 独立预期（3 升杯 / 5 升杯） | 三份结果 |
| --- | --- | --- |
| 首次六步达成并刷新 | 3 / 4，当前成功 | 一致 |
| 倒空另一杯并刷新 | 0 / 4，仍然成功 | 一致，未冻结探索 |
| 空格键装满目标杯并刷新 | 0 / 5，当前不成功 | 一致，旧成功文字消失 |
| 倒空目标杯、重置 | 0 / 0，不成功；重置后步数归零 | 一致 |
| 再次达成，再装满并刷新 | 先 3 / 4 成功，再 3 / 5 不成功 | 一致 |

随后通过真实模型追问：“我刚才不是量出4升了吗？现在两个杯子各是多少，还算成功吗？”三份均正确回答当前 3/5 升、不算成功，并区别历史达成与当前条件。第一份还建议撤销，单步证据可核对回到 3/4；另两份额外给出六步路线，独立容量状态搜索确认从 3/5 到 4 升的最少动作数是 6。这些补充核对不计入 desktop 操作数。
