# 第三阶段成果：按窗口判断三维可用性

2026-11-02 | 专用 worktree：intelligent-ui/Piora | 分支：codex/intelligent-ui

## 1. 本批成果与边界

**三维能力已从固定关闭改为按消息发起窗口检测，并贯通模型提示、接纳、执行和发布复核。** 这是一项第三阶段增量；完整自然语言三维任务、其他复杂交互及第三阶段验收尚未完成。

| 场景 | 现在的行为 |
| --- | --- |
| 当前窗口能创建并读取 WebGL2 | 结合当前源码、能力证据和平台条件，向本次运行开放三维能力 |
| 不支持、探测失败或缺少报告 | 继续发送普通消息；三维能力保持不可用 |
| 另一窗口提交报告 | 独立判断，不替换当前运行的原始窗口绑定 |
| 生成中关闭窗口或丢失图形上下文 | 撤销环境；发布前再次核对，拒绝依赖失效环境的新候选 |
| 刷新后读取既有场景 | 在实际承载内容的 iframe 再检测；不可运行时保留静态结果和检查点 |

报告是可用性信息，不是权限。Beta 设置仍是入口；普通聊天只调用通用输出预检，探测与运行状态继续属于独立小程序模块。新增环境协议 mini-app-renderer-2；三维交互计划继续使用 mini-app-1.4。

本批真实模型测试固定配置为 DeepSeek V4.1 Flash，provider/id 为 deepseek/deepseek-flash，没有使用 Pro 或模型回退。配置名称不能独立证明供应端精确版本。

## 2. 实现与确定性验证

隐藏的可信渲染器执行真实 WebGL2 清屏及像素回读。客户端在原消息发送前，以 sessionId + submissionId 关联版本、资源摘要、窗口实例、epoch 及序号；SDK 运行开始只绑定一次。没有原始报告的运行不能被迟到报告升级。

每 15 秒发送心跳，3 分钟失效以容纳后台计时器限速；关闭、Beta 关闭及图形上下文丢失立即请求撤销。记录替换或资源变化使旧引用失效；旧心跳不能恢复已关闭的实例。服务端仅保留有界内存状态。

| 检查 | 结果与范围 |
| --- | --- |
| 相关能力验证 | 156/156 通过，24 个测试文件；记录位于 mini-app-capabilities-luXkdp |
| 真实浏览器窗口 | 可信 WebGL 探测、普通消息预检、生产环境 API、双窗口隔离及关闭撤销通过；消息执行使用 HTTP 夹具 |
| SDK 入口及发布 | UI 提交身份贯通真实 wrapper；没有环境不能生成场景，试运行后撤销环境会拒绝发布 |
| 保存与追问上下文 | 生产保存保留参数、选中对象与用户镜头；运行上下文包含已确认状态 |
| 开发检查 | TypeScript 与 26 个相关文件 lint 通过；模型中继另有 7/7 检查及 3 个文件 lint |

能力证据绑定本次源码摘要。浏览器测试使用软件 WebGL，不外推为所有显卡兼容。首次类型检查误用了不存在的 TypeScript 入口，修正为仓库 tsc 入口后通过；首次新增桌面脚本 lint 有未使用导入警告，清理后通过。

## 3. 真实桌面与模型记录

真实开发桌面已成功上报当前窗口 WebGL，并且实际模型请求中的能力清单包含 scene3d、scenePicking 和 cameraControls。第一次请求在流式响应解析阶段失败，未产出可操作界面，已保留失败记录 desktop-e2e-FJsaR7。

第二次运行 desktop-e2e-XlCGaz 在 6688 个 SSE 事件后触发测试中继的传输上限。中继现将传输流与生成内容分别限制为 8 Mi / 2 Mi 字符，仍保留上限拒绝及截断失败检查；产品程序和执行预算不变。

第三次运行 desktop-e2e-pLBSQ3 收到正常结束的响应，但 8192 个输出 token 全用于思考，未生成工具调用。原因涉及测试配置遗漏模型 reasoning/compat，导致 SDK 没有发送“关闭思考”；现保留本机模型配置、记录实际请求参数，并为复杂任务使用最多 32768 token 的测试上限。

第四次运行 desktop-e2e-iEqvz1 确认请求使用 thinking: disabled，返回模型为 deepseek-flash。模型调用三维工具，但首试包含不支持的 @media(min-width:640px) 和顶层 const DEG=Math.PI/180；重提时增加了未知字段 viewport_placeholder。下一次调用被既定纠错上限拒绝，模型最终说明无法生成。没有界面发布，操作、保存、刷新及真实追问均未执行，不能写成通过。

该样本说明当前能力已经到达真实模型，生成可靠性仍需改进。测试中继修复不能替代生成质量优化；本批保留协议校验及纠错预算，没有为了通过样本放宽产品规则。场景后来增加“模型已结束但没有发布”的快速失败判断，避免空等，尚未再次运行真实模型。
