# 浏览器、投屏与文件引用回归

开发始于 beta.16，并同步 beta.17 与 CI 提速改动，在独立 worktree 完成；不在开发目录执行 Next 生产构建或本地发布打包。发布包验收由远端 Actions 执行。

## 已执行

- 根与桌面 TypeScript 6 检查，以及项目默认 TypeScript 7 检查通过。
- 同步主分支后相关快速回归 137 项通过；浏览器扩展、用户等待和投屏会话集成回归 35 项通过。
- ASAR 原生资源与动态依赖闭包夹具通过，新增固定清单、防篡改字节与完整许可证校验。此工作树使用依赖目录 junction，需要 `node --preserve-symlinks --test lib/harmony-packaging.test.mjs`，否则既有的目录边界保护会正确拒绝外部真实路径。
- 实际浏览器 DOM 的登录交接、当前已登录状态、无用户标记的 SPA、保留 `/auth` 路由和验证码输入回归通过；无标记 SPA 初测 2351 毫秒，缩短观察窗口后复测 1804 毫秒，均低于 3 秒。
- 生产组件浏览器回归通过：新会话拖动与刷新恢复、模型无默认标签；过程自动折叠、用户手动状态保留，以及 14/16/18 号字体的摘要对齐。新会话按最新要求保留原有文字标题。
- 投屏组件与真实媒体状态 hook 回归通过：错误发生时画布尺寸与位置保持，关键帧恢复优先于重连，错误后可手动重连；离线和替换 worker 期间保留上一帧，新设备 epoch 清除旧帧。
- 截图/录屏通知回归通过，通知宽度不超过 300 像素、高度不超过 76 像素；浅色、深色及主题背景下可读。桌面消息与 DPI/窗口夹具通过，不把夹具当成完整发布安装验收。
- 文件引用通过生产 Markdown 与 FileViewer 浏览器回归：普通引用、行内代码、Windows 链接的行列信息保留，右侧源码滚动并高亮；切换后对话草稿与 URL 保持，越界路径与不存在文件有明确提示。
- 新视频库从固定归档重新提取，与清单全部 hash 一致；许可证清单、changelog 片段及差异格式检查通过。

## 初测发现与复测

旧测试中依赖已移除标题、默认标签和旧投屏版本选择的断言随行为更新，补充了相应新行为断言。界面回归进一步发现过程计数使用等宽字体/不同字号、文件定位需等待源码行生成；已修复后复测。文件引用浏览器夹具补齐 EventSource 事件接口，未以跳过或降低产品断言掩盖失败。

PR #389 首轮远端 CI 的发布卫生检查拒绝了文件引用单测中的本地仓库路径，已将夹具改成通用工作区路径；原有路径、行列和边界断言保持。

后续 CI 提示 Markdown 链接的严格 HTML 断言需要同步完整路径悬停信息，以及英文环境的语言初始化会让投屏夹具多创建一次 worker；已更新断言、固定夹具语言，相关回归 15 项通过。

项目目录进一步按要求设为长按 500ms；生产侧栏浏览器回归验证 499ms 不进入拖动、500ms 进入拖动并实际投放排序，项目与按钮分别显示抓取/点击手势。与项目排序单测合计 8 项通过。
