## 1 默认路径与用户可见变化

开启 Beta 后，当前开发版本默认提供 Plan2。用户无需配置环境变量，即可请求分组界面、方案卡片、筛选表格、增量预览，以及受限的读取参数／另存结果按钮。普通对话继续通过独立的回答输出接口接入；功能默认仍关闭。

新模块 input-protocol.ts 统一选择扩展加载时的协议。未设置环境变量或显式 plan-2 使用新协议；显式 surface 和 plan-1 保留开发回退，未知值沿用旧回退行为。更改环境变量后需重启服务；旧历史不会因此改写。

### 可以这样试

- 在设置中开启 Intelligent UI，新开对话。若此前显式设置了旧协议，先清除该覆盖并重启开发服务。
- 输入：“周末我们4个人出去玩，门票每人30元，吃饭每人40元，车费一共120元。我想来回改人数和每人餐费，看各项、总共和每人多少。再给个保存结果的按钮，保存成项目里的 result.json。”
- 把人数改为 6、每人餐费改为 50，核对总费用 600 元、每人 100 元。点击保存，再刷新并追问：“按刚才改好的参数，总共多少钱？直接说就行。”
- 对照测试：“4个人，门票每人30、餐费每人40、车费120，一共多少？直接告诉我。”应优先给文字答案，而不是再开界面。

## 2 开发集基线：240 次真实模型调用

冻结第一阶段工具与提示词，在 40 个开发任务上，对 DeepSeek Flash 和 V4 Pro 各独立运行 3 次：每模型 120 次，共 240 次。20 个封存任务本轮未使用。每模型的 40 个任务包含 20 个应交互、14 个直接回答、3 个澄清和 3 个不支持任务；三次重复不视为新增独立任务。

| 观测结果 | Flash | V4 Pro |
| --- | --- | --- |
| 完成整个任务回合 | 73 / 120 | 95 / 120 |
| 供应商错误 | 34 / 120 | 22 / 120 |
| 超时或评估预算终止 | 13 / 120 | 3 / 120 |
| 应交互任务中未尝试 UI | 3 / 60 | 6 / 60 |
| 直接回答回合中尝试 UI | 3 / 48 | 3 / 48 |
| 完成回合且首次结构有效 | 20 / 60 | 38 / 60 |
| 完成回合且存在结构有效尝试 | 35 / 60 | 45 / 60 |

设置一致：low reasoning、6000 最大输出 token、最多 4 次模型请求和 3 次工具执行、120 秒任务超时、无网络重试。直接回答的 48 个回合包含多轮任务中的文字追问，不能与 14×3 个单任务标签混用。

以上是隔离的生成基线。编译有效不代表计算、语义、联动、持久化正确，completed 也不等于可用。供应商失败保留在分母；未调用 UI 可能由供应商中断造成，不能全部归因于触发策略。错误码包括结构无效、参数 schema 无效、工具预算终止和供应商错误。

本轮没有候选协议的同规模对照，也没有两名独立人工审阅者，首次／最终可用率继续标为待验收。证据 JSON 保留逐任务终态、错误码、次数、模型设置和原始文件哈希，不包含凭据或隐含推理。当前仅能报告原始计数，不宣称统计稳定或跨模型泛化改善。

证据：同目录 intelligent-ui-phase2-baseline-2026-10-29.json。完整本地运行记录位于 .verification/intelligent-ui-development-baseline。

## 3 真实桌面结果与尚存问题

在 Windows Electron 45 开发桌面中，使用独立测试配置、工作区和真实 Flash 模型，未设置协议覆盖。模型通过实际 Next HTTP、生产 SDK 和扩展生成 Surface2，随后通过真实控件和按钮完成保存、刷新与追问。

| 检查 | 本次结果 |
| --- | --- |
| 初始界面 | 4 人、餐费 40，合计 400 元 |
| 修改及持久化 | 6 人、餐费 50，合计 600 元、人均 100 元 |
| 点击另存 | result.json 中参数与当前已保存参数一致，快照为 600 元 |
| 刷新恢复 | 控件仍为 6 人、餐费 50 |
| 普通追问 | 回答 6 人、600 元、人均 100 元；没有新 UI 调用 |

该回合首次生成因重复节点 ID 返回 PLAN_ID，模型在允许的一次纠错内完成第二次调用。界面标题仍含初始“4人”，修改后成为过时文字；这属于已确认的语义缺口，不能把本次技术流程通过写成完整语义通过。禁止用关键词替换标题来掩盖问题；后续需要通用的静态文案约束与变参核对。

前四次桌面尝试全部保留：第一次缺少 Electron 二进制；第二次测试脚本过早刷新中断启动；第三次 180 秒内未拿到生成结果；第四次已生成并保存参数，但新配置的首次引导挡住按钮。修复脚本启动等待、正常跳过引导并为隔离配置增加 45 秒网络闲置超时后，第五次完整流程通过。不能据此计算产品成功率。测试结束关闭其专属进程，删除复制的认证与模型配置，未更改用户日常配置。

桌面证据：同目录 intelligent-ui-phase2-desktop-2026-10-29.json；本地各次记录位于 .verification/desktop-phase2-default*。本轮只验证 Windows 单模型、单个保存动作；读取参数、其他权限模式、取消、窄窗口、键盘可达性及其他操作系统仍需完整桌面矩阵。
