## 两项产品修复

- SVG 留白下拖动偏移：旧实现按整个 CSS 矩形缩放坐标，忽略 SVG 等比缩放后的留白。原始三角形垂直拖动 C 时，x 从 60 错移到 90；浏览器回归中圆心 x=40 被上报为 75。现改用实际 SVG 视图变换的逆矩阵，覆盖非零 viewBox 原点、宽窄容器及变换；无法映射时释放输入。
- 空格不能激活原生按钮：宿主统一阻止空格默认行为，使仅监听点击的棋盘无法用空格落子。现在保留原生按钮的默认激活，普通空间目标仍避免方向键、空格滚动。回归核对 Space、Enter 各产生一次点击。

坐标依据采用 [SVG 2 坐标变换规则](https://www.w3.org/TR/SVG2/coords.html#ComputingAViewportsTransform) 和浏览器 [getScreenCTM](https://developer.mozilla.org/en-US/docs/Web/API/SVGGraphicsElement/getScreenCTM)。宿主修复不改模型的公式、状态结构或任务内容。
