# 第三阶段：能力清单与生成接纳

2026-11-02 | 3B 实施报告 | 第三阶段尚未完成

## 1. 本批实现

小程序的工具说明、当前轮上下文、参数接纳和发布前复核，现在读取同一份能力状态。声明了语法或渲染原型，不再自动等同于当前能够生成并执行。已有小程序的编译、读取和状态恢复不经过新增生成门禁。

新增 manifest 记录通用能力 ID、版本、实现状态、依赖、事件、视图、预算、示例标识和验证所需源文件；不以排序、倒水等业务题目建立白名单。状态为 planned、implemented、verified；只有当前证据有效、依赖满足且环境允许的能力进入普通生成路径。

| 能力 | 当前实际状态 |
| --- | --- |
| 文档与显式计算 | verified：有界 HTML/CSS、表单、绑定、隔离计算与显式状态 |
| 本地事件 | verified：有序指针、键盘和失焦事件，附浏览器夹具证据 |
| 推进与播放 | verified：离散单步、固定时间步、暂停、终态和检查点 |
| SVG / Canvas 2D | verified：基础几何、属性绑定及可信绘制命令 |
| 基础三维场景 | implemented：已有原型；尚未确认当前浏览器 WebGL 环境，普通生成暂不可用 |
| 动态列表、三维拾取、相机 | planned：完整实现和验证仍在第三阶段范围内 |
| 登记动作、状态迁移 | planned：小程序执行/迁移适配仍待完成，不因协议能声明就视为可执行 |

上述 verified 限于 Windows 主机上的确定性 SDK、QuickJS 和无头浏览器/Controller 检查，不代表真实模型任务语义、原生窗口或跨平台 GPU 已通过。能力本身通过验证，也不能保证每个生成程序正确；每份结果仍需编译、试运行和任务核对。

### 模型看到的能力与执行相符

每轮更新独立的能力上下文，不混入用户指令或工具授权。工具说明按可用能力提供 SVG、Canvas 和三维相关契约；当前不提供三维的生成示例。公共语义选择原则仍由同一回答模型使用，没有新增分类请求或关键词路由。

对于已经能编译、但没有小程序动作执行器的 actions 声明，SDK 在权限和执行之前返回 CAPABILITY_UNAVAILABLE。诊断说明具体能力，不鼓励在同一轮反复尝试不可用操作。已有回答保持可读；第二阶段组件动作路径不受此门禁影响。

## 2. 证据、环境与历史兼容

### 证据必须匹配当前内容

验证记录保存能力版本、主机平台、检查范围、检查列表和内容摘要。校验对象包含相关编译、事件、Controller、生成代码，以及实际 renderer、server-worker 和 QuickJS WASM 资源。缺失、损坏、版本或平台不匹配、摘要变化都会撤销普通生成资格。

当前多项能力共用核心运行时，因此共用依赖摘要；修改公共文件可能使多项证据一起失效。这是明确的依赖范围，不声称已经做到每个 CSS 属性或每个图形命令独立失效。证据失效不改写历史程序身份、发布回执或保存状态。

```text
manifest + 当前源码/资源摘要 + 验证记录 + 主机环境
  -> 当前能力状态
  -> 工具说明 / 每轮上下文
  -> 原始参数接纳 / 实际执行 / 发布前复核
```

验证文件只包含宿主拥有的记录；读取路径来自固定 manifest，生成计划不能提供文件路径或开放开关。WebGL 是浏览器属性，当前服务端不凭 Node.js 环境推断支持；后续必须接通实际渲染端能力协商及相应验证后，才能开放三维生成。

### 隔离开发验证入口

新增 scripts/verify-mini-app-capabilities.mjs：准备测试所需运行资源，在临时 agent 配置中运行 12 个直接相关测试文件；确认检查通过且测试期间源码/资源未变化后，才写入证据。失败不提升验证状态，原日志保留。

开发模式只能在非 production、显式 development 开关、非默认 agent 目录下启用；目录比较处理真实路径别名。它可以测试 implemented 能力，但不会把其状态伪装成 verified，也不能开放 planned 能力或绕过环境要求。这个开关不由模型计划或请求参数控制。

### 普通模式与历史路径

新增门禁只用于新生成与新候选发布。原有计划解析、历史投影、状态读取和恢复不要求重新取得生成证据；测试确认带旧动作声明的计划仍可编译读取，而相同新计划会在接纳阶段被拒绝。

同时补齐 standalone 暂存清单中的组件 UI 扩展、小程序扩展及运行资源；原有 lib 暂存会包含证据 JSON 和相关源文件。本次只修改清单并检查代码，没有运行 next build、本地安装包或发布构建，不能据此称打包通过。

| 检查 | 结果及限制 |
| --- | --- |
| 隔离开发验证 | 最新证据批次 51/51 Node 测试项通过；覆盖确定性 SDK、原始参数、编译、Worker、浏览器、事件、播放与绘图 |
| 普通配置复测 | 26/26 通过，含新增“不可用动作在权限和执行前拒绝”断言；与前一批重叠，不相加为 77 个不同场景 |
| 当前宿主快照 | development=false；document、events、playback、svg、canvas2d 为 verified 且 available；其他能力未开放 |
| 失效机制 | 依赖摘要、能力版本、平台或环境不符时拒绝；缺失证据和 planned 能力不能被开发模式提升为已验证 |
| 提示与接纳一致性 | 同一快照控制提示中的具体能力说明与计划接纳；当前不支持的三维计划、动作声明被拒绝 |
| TypeScript / lint | tsc --noEmit 通过；本批 11 个修改模块 lint 通过 |

验证脚本先运行一批 51/51；随后加入运行资源摘要与真实路径处理，再运行新的 51/51 固定内容批次。最后增加 SDK 拒绝动作的断言并完成普通配置 26/26 复测。两个开发批次分别保留，最新能力证据对应后一个批次；没有把旧记录覆盖成新版本成功。

本轮没有调用真实模型，没有进行真实桌面窗口、跨平台、GPU 兼容、完整 CI、人工语义或安装包验收。普通配置复测仍使用确定性模型夹具，不是 DeepSeek 生成质量报告。后续真实模型仍按用户要求使用 DeepSeek V4.1 配置，不使用 V4 Pro。
