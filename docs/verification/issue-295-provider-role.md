# #295 角色字段错误诊断

当前 SDK 1.4.0 的 OpenAI Chat Completions 转换在本地夹具中将技能文本、自定义消息、工具调用及工具结果转换为 user/user/assistant/tool，未复现华为云原始错误。本结果不代表真实华为云兼容性通过。

新增校验位于 SDK onPayload 边界，在既有回调完成后检查最终 messages 的 role；既有回调的原地修改和替换返回值均覆盖。错误仅包含数组索引，不收集提示词、工具内容或凭据，也不把缺失角色静默改为 user。其他协议不应用此校验。

界面展示 error_msg/message 与错误码，可展开原始错误。原始错误仍保留在消息中，重试和模型回退继续使用原始原因。定向测试确认原始确定性 400 及本地角色错误不自动重试；现有回退测试仍通过。

仍需由原环境提供的证据：渠道 API 类型、SDK/应用版本、是否经过自定义 onPayload 或网关改写、能否用不含真实内容的最小技能复现。不要提交密钥、完整对话或原始请求正文。该 issue 在原始原因确认前保持打开。
