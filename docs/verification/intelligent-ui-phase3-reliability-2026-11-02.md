# 第三阶段成果：生成纠错与输入顺序

2026-11-02 | 专用工作树 intelligent-ui/Piora | 分支 codex/intelligent-ui

## 1. 本批完成的改动

**修正快速输入被旧结果覆盖的问题，并改进形式选择和一次纠错的信息。** 相关开发检查通过；真实生成和解释仍有失败，第三阶段尚未完成。

| 改动 | 实际行为与边界 |
| --- | --- |
| 普通输入顺序 | 原生数字框、选择项等携带宿主顺序号；迟到投影不能覆盖未确认的新值，合并输入后按顺序确认 |
| 复位边界 | 复位只确认调用时被取消的旧输入，不提前确认其后刚输入的值；顺序元数据不进入生成程序 |
| 三维选择 | 已确认的选择值未变化时不重复赋值，保留原生下拉框正在进行的键盘选择 |
| 回答形式 | 计算、条件结果、表格和图表优先组件；任务进度、空间操作和超出表达式能力的计算再选小程序，无关键词路由或额外分类模型 |
| 有界纠错 | 语法错误给出行列，完整重提列出所有必填键；版本缺失或已知版本混淆可使用原有一次纠错，不接受未知版本 |
| 布局诊断 | 不支持的 auto-fit/auto-fill 返回可修正的契约错误；九列及以上、尺寸和其他资源超限仍拒绝，不自动删减任务 |

共用预算仍为 3 次接纳尝试、1 次纠错和首次尝试起 60 秒。没有增加重试次数、扩大运行预算或改写模型的公式。策略更新为 answer-form-2 / mini-app-intent-20；历史程序身份及权限边界保持兼容。
