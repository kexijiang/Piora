# 第三阶段操作差异与追问复测

2026-11-03 | 3B 当前状态与反事实证据 | 第三阶段尚未完成

上一批已验证只读预演可以正确计算，但模型仍会错误解释。本批把结果表达改为宿主计算的逐字段差异，减少每个备选操作重复的目标说明，继续使用相同原始程序和自然追问，并扩展到棋盘和排序。

## 从完整快照到可核对的变化

预演仍在隔离 Worker 中执行，每个按钮独立从同一已确认快照开始。计算、参数、保存、时钟与随机状态的归属没有改变。新增的差异器逐项比较操作前后值，不按任务名称或字段关键词猜测含义，不调用另一模型进行分类。

| 情况 | 差异表示 | 解释边界 |
| --- | --- | --- |
| 数值或内容改变 | 路径、原值、新值 | 例如杯内水量 4→0，排序元素 6→1 |
| 字段新增或删除 | 单独的 add/remove 类型 | 缺少字段不能当作 null、0 或 false |
| 列表改变 | 当前位置的路径与值 | 数组下标不是稳定对象身份，不推断业务对象迁移 |
| 内容过大或变化过多 | 省略数与 complete=false | 只有 complete=true 才能说未列字段没有改变 |

变化最多保留 12 项，单个前值/后值最多 256 字符，变化列表最多 1200 字符；被省略的变化仍计入总数。完整状态超过快照预算时，小而明确的变化仍可保留。宿主再次核对路径、原值、数量及重复/重叠路径；完整结果可用时重算差异并拒绝不一致证据。

模型上下文使用 version 2，不再为每个备选重复完整快照与生成的结果摘要；仍保留来源身份、按钮标签、完整检查点是否变化，以及具体变化。检查点变化可能只是提示文案改变，不能直接等同于用户目标被破坏。每份上下文证据仍最多 4500 字符，总状态上下文仍最多 11000 字符；Worker 的预演证据传输上限由 24KB 调整为 48KB，模型可见预算没有增加。

只读预演协议变化不修改历史计划身份或保存格式。取消、关闭实验功能、版本绑定、缓存、错误降级和不写回状态保持上一批边界，不声称支持多步规划或最短路线证明。

## 原始任务的真实桌面复测

沿用原始程序、操作轨迹和追问，固定 DeepSeek V4.1 Flash 配置，实际 deepseek/deepseek-flash，开启推理、关闭回退，未使用 Pro。返回 ID 不能独立证明服务内部修订。五份任务完成 58 项 UI 操作，其中含 12 次刷新，再完成 5 次真实模型追问；原始文件摘要不变，追问后保存快照和版本不变，清理无错误。

真实请求共携带 36 个按钮预演。独立预期核对了 50 对指定字段的前后值，包括量杯七类操作、棋盘在空格落 O、排序下一次交换；不通过模型文字或程序自身公式生成预期。

| 任务 | 本批覆盖 | 回答观察 |
| --- | --- | --- |
| 三份量杯 | 各 8 项操作、2 次刷新；各 8 个预演全部包含 | 当前 3L/4L 均正确；两份仍说任何操作都会破坏结果，另一份额外建议有歧义 |
| 棋盘第二份 | 22 项操作、3 次刷新；10 个预演 | 正确说明只有中心 X、轮到 O，尚无胜负 |
| 排序第一份 | 12 项操作、3 次刷新；2 个预演 | 正确说明已比较/交换各 2 次、上一对 6/5，以及下一对 6/1 与第三次交换 |

量杯第二、第三份同时承认满杯无法接水，却仍概括“任何动作都会破坏结果”，与倒空另一只杯子仍保留 4L 的证据矛盾。第一份说任何操作都会“改变现状”；其提示文案确实会变化，但这一说法可能让用户误解目标水量也会丢失，保留待复核，不强行判为明确数值错误。棋盘与排序的结论由开发审阅核对，不代替独立人工验收或整体语义通过率。

在相同量杯检查点离线比较证据：第一份由 2588 变为 2930 字符，第二份 2395→2336，第三份 4342→3344，按相同口径不计额外来源包装。第三份由 6 个预演增加到完整 8 个；并非所有任务都压缩了上下文。真实请求也确认三份各 8 个，无省略。

## 结论与剩余任务

本批证明通用差异表示、完整性边界和跨任务状态核对可用，也让大状态中的小变化保持可见；没有证明它足以消除错误解释。继续把证据可靠性与自然语言正确性分开评估，不把绿色机械测试当作 3B 完成。

后续需继续约束未经证据支持的概括和建议，并区分提示状态变化与业务目标结论；同时推进 3C 原生窗口及恢复/修订交叉矩阵、3D 复杂列表/持续模拟/三维任务。3B 其他静态说明与多轮澄清、3E 完整 CI/封存集/双人人工验收仍按现有进度和用户安排保留。本批未发布、未打包，第三阶段继续开发。
