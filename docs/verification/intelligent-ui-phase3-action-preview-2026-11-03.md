# 第三阶段只读操作预演

2026-11-03 | 3B 追问证据与隔离运行器 | 第三阶段尚未完成

上一批出现界面计算正确、模型追问解释错误的问题。本批接入实际运行器的局部操作预演，分别验证证据是否正确、是否保持用户状态，以及模型是否正确使用它。不能把运行器通过写成回答正确。

## 实现与边界

- 从当前分支已确认的程序与检查点出发，在现有 Worker/QuickJS 中分别执行已声明按钮的局部点击；离散步骤使用与真实操作相同的转换逻辑。每个备选都从同一快照开始，不串联前一个结果，不改变用户参数、状态、时钟、随机数或保存版本。
- 结果绑定程序摘要、检查点摘要和状态版本。内部发布身份只用于缓存，不进入模型上下文。每个运行最多缓存 16 份证据，状态或程序改变即使用新身份，运行结束清空；取消、关闭实验功能及所有权失效沿用现有撤销边界。
- 每次上下文最多为最近两份已包含的小程序获取预演，每份最多 12 个局部按钮，沿用每个操作 8ms、Worker 5 秒及全局两任务并发上限。原生禁用按钮不执行，生成程序仍不能访问宿主文件、网络、进程或授权动作。
- 每份证据最多 4500 字符，结果摘要最多 384 字符，大于 1200 字符的结果快照整体省略。总上下文仍为 11000 字符；优先保留确认状态，按完整结果移除多余预演并记录省略数，容量不足则不附加。最近程序优先，证据不挤掉已有状态。
- 失败只使可选预演不可用，保留当前确认值。它不代表用户已执行动作，不验证屏幕可见性、连续操作、最短路线、任意输入、拖动、列表、三维选择或外部动作。程序自身的文字摘要和业务规则仍需独立核对。
