# 第三阶段成果：参数归零与预设

2026-11-02 | 专用 worktree：intelligent-ui/Piora | 分支：codex/intelligent-ui

## 1. 从按钮承诺到实际参数

**小程序可以声明参数预设，由宿主一次更新多个控件。** 此前真实模型生成的“角度归零”只改变了镜头版本，参数仍保持原值；生成程序不能写只读的 ctx.inputs。本批提供明确的本地输入入口，适用于归零、恢复默认和有限示例，不依赖飞机或其他任务关键词。第三阶段尚未完成。

| 行为 | 契约 |
| --- | --- |
| 声明预设 | inputPresets 中提供 id、label、values，最多 16 个，每个至少一个合法输入值 |
| 声明按钮 | 每个预设对应唯一的 plain button / data-preset，文字及无障碍标签来自 label |
| 可信点击 | 只发送预设 ID；未知目标、额外 values、混合事件和嵌套绑定被拒绝 |
| 更新规则 | 合并到当前参数；未列出的参数保留当前值，不回退到默认值 |
| 程序执行 | 按输入声明顺序发送普通 input 事件，所有处理函数看到完整新参数，只投影一次 |
| 状态边界 | 暂停播放，不自动 init，不清除进度、随机状态、步数和用户镜头 |

新契约采用 mini-app-1.6；旧计划未使用预设时保留原版本和身份。预设没有外部权限，不能请求文件、网络或工具动作。整个事务仍受普通 8ms 限额约束，不能领取启动额度。业务状态如何响应参数，继续由普通输入处理函数明确实现。

发布前从初始检查点分别试运行所有声明预设，错误保留对应预设 ID；发布结果不会带上试验参数。它不能证明其他历史或所有组合。读取历史记录不追加探测。保存会等待完整事务，刷新恢复同一确认状态。

## 2. 开发验证

相关能力检查 **182/182 通过**，27 个测试文件，证据目录 mini-app-capabilities-5Rrc6N。本批新增 7 项预设契约检查及 1 项序列化边界检查，并扩展既有两组真实浏览器测试，不与此前 174 项累计。TypeScript 与相关文件 lint 通过。

检查覆盖旧版本身份、能力门禁、输入类型与边界、按钮唯一性、宿主标签、伪造 values、完整新参数与声明顺序、保留未列出的当前值，以及发布试运行和历史读取。数值、开关、文本及选项均受原有类型约束；限时检查确认事务没有扩张启动预算。

浏览器用原生按钮验证部分归零与全部归零、控件显示、选择及用户镜头保留、保存刷新；合成 DOM 点击不能更新参数。播放场景确认预设会暂停，等待后检查点不再推进。一次旧恢复断言仍期待预设前的数值，已改为比较完整的新预设检查点并复测通过，保留失败日志。

真实模型生成后首次调整角度触发 TIME_LIMIT，尚未走到预设按钮。本批发现同一帧在普通操作预算内被完整遍历两次，改为分段验证后组装受限回包；总节点数、实际信封深度、UTF-8 字节及原有提前大小检查均保留，没有提高 8ms 限额。新增边界用例同时覆盖“各部分合法、合计超限”和多字节文本。序列化测试使用专门固定时钟隔离数据边界，既有真实限时与死循环测试继续使用正常时钟。

固定 DeepSeek V4.1 Flash 配置，provider/id 为 deepseek/deepseek-flash，thinking: disabled；未使用 Pro 或回退。精确供应端版本仍不能只凭返回 ID 证明。

自然任务沿用飞机俯仰、偏航和横滚，并补充一句：“也让我能一键把角度归零。”测试按声明逐一点击预设，检查生产保存的完整输入与原生控件，然后刷新并真实追问；生成、流程与语义分别记录。

desktop-e2e-SgQpdj 生成并发布了归零、单独俯仰、单独偏航和单独横滚四个预设，但首次操作触发 TIME_LIMIT，不能记为流程通过。原始程序不改写。六次离线定时诊断中，优化前单次输入约 3.2–6.5ms，优化后约 2.2–5.6ms；这些短样本包含宿主校验，不是跨设备性能基准，也不是浏览器耗时。

原样桌面重放 desktop-e2e-HmdUOO **流程通过**：调整俯仰到 -57°、选择参考机身、换视角后，逐一点击四个预设；对应三个角度分别保存为 (0,0,0)、(30,0,0)、(0,30,0)、(0,0,30)。未列出的参考体开关、选择和用户镜头保留，状态版本从 2 推进到 6；刷新恢复并完成真实模型追问。没有运行时错误，测试进程清理无错误。原始程序日志 SHA-256：09ea3567…97a7f1c。

追问正确读取了当前选择、角度与单独保存的镜头；它对转动方向及镜头操作方式的解释未获得独立语义验收。一次原样重放通过不能替代新生成的稳定性统计、完整三维正确性或跨设备性能结论。
