# Intelligent UI 第二阶段增量报告

v2.13 · 2026-10-30 · 封存集对比与桌面动作修复

当前处于开发与验收收尾，尚未发布。按用户安排，CI 留到三个阶段功能开发后统一处理，不以 CI 阻塞阶段间推进。本报告记录本次增量，保留此前各版本证据。

## 1 修复真实桌面动作流程

实测发现：模型生成界面后，聊天自动命名会追加 session_info 标题记录。原来的动作来源摘要把标题变化当成分支变化，导致读入参数无法采用，保存确认或拒绝返回冲突。

修复只在动作身份中折叠末尾无分叉的标题记录。参数仍从实际历史叶子读取；真正的分支、消息、参数或界面变化继续阻止旧动作。过期确认会结束等待，修改参数后仍可拒绝，同一个确认只消费一次。

### Windows 桌面复验

使用真实 Flash 模型、Electron、Next HTTP 和默认 Plan2；独立测试目录与配置。初始 4 人、餐费 40 元/人、门票 30 元/人、车费 120 元。读入后为 7 人、餐费 55 元/人，总额 715 元。

| 操作 | 结果 |
| --- | --- |
| 读取参数后刷新，再点击采用 | 读取不自动改值；刷新保留待采用结果；明确采用后生效 |
| 拒绝保存、取消保存 | 均不创建文件，当前参数不变 |
| 等待保存确认时把人数改成 8 | 旧确认被拒并结束等待，保留 8 人，不写文件 |
| 恢复 7 人并重新确认保存 | 确认前无文件；确认后 JSON 与当前参数一致 |
| 再保存到已存在的文件 | 拒绝保存，已有文件字节不变 |
| 刷新并追问当前人数与总额 | 恢复 7 人、55 元；回答 7 人、715 元，没有再次生成 UI |

最后一次复验已等到服务端空闲。截图已查看；客户端状态提示可能稍晚于服务端更新，本轮没有把截图作为客户端终态断言。测试凭据已清理，专用进程已退出。

## 2 冻结封存集的同条件对比

本轮共 26 个任务族：10 个交互、6 个文字、5 个澄清、5 个能力边界；两模型、两协议、各重复三次，共 312 次任务。含文字追问后，每个模型/协议组合有 30 个交互任务、21 个文字回合、15 个澄清回合和 15 个边界回合。

原 20 个封存任务未改动，补充 6 个边界任务。任务、标签、数值期望和判分规则均在模型调用前冻结；旧协议与 Plan2 按任务交替执行。原协议使用冻结的第一阶段工具与当前宿主接纳路径，不代表历史发行版的端到端表现。

| 观察值 | Flash 旧协议 | Flash Plan2 | Pro 旧协议 | Pro Plan2 |
| --- | --- | --- | --- | --- |
| 完成且首次结构有效 | 24/30 | 28/30 | 27/30 | 29/30 |
| 预算内完成且最终结构有效 | 28/30 | 29/30 | 30/30 | 29/30 |
| 首次数值轨迹匹配 | 18/30 | 28/30 | 23/30 | 29/30 |
| 最终数值轨迹匹配 | 24/30 | 29/30 | 27/30 | 29/30 |
| 应交互却没有 UI 尝试 | 0/30 | 1/30 | 0/30 | 0/30 |
| 应交互任务中多次尝试 | 12/30 | 5/30 | 9/30 | 4/30 |
| UI 耗时 P95（含失败） | 120.00 秒 | 18.65 秒 | 35.42 秒 | 28.33 秒 |

模型条件：low、最多 6000 输出 token、每回合最多 4 次请求、供应商重试 0、任务期限 120 秒。实际 UI 接纳沿用 3 次尝试、1 次纠错、60 秒活动窗口。两模型的声明依赖与快照哈希一致；快照覆盖 23 个声明文件，不等于整个依赖闭包。

运行结果：Flash phase1：completed 78；Flash plan-2：completed 77、provider-error 1；Pro phase1：completed 76、timeout 2；Pro plan-2：completed 76、provider-error 1、timeout 1。以上失败全部保留，没有补跑替换。Flash 达到六项技术开发目标；Pro 达到六项技术开发目标。失败 UI 任务按至少 120 秒计入最近秩 P95，完成文字降级也不算 UI 成功。

Pro 新版最终结构有效比旧协议少一次，数值匹配则多两次；不能宣称每个指标都改善。Flash 五次、Pro 四次多调用也不全是纠错，包含生成有效版本后的再次更新。

数值检查独立改变输入并核对预先写定的输出轨迹；它能发现“格式合法但结果写死”等问题，不能证明所有边界输入、文案或业务语义正确。重复三次用于观察稳定性，不能把 26 个任务族当成 78 个独立任务族。

### 当前结论与剩余工作

- 这批任务提供有限的跨领域证据，仍共享已有算术与组件能力。封存任务现已暴露；若据其输出调优，应转为开发集，并另补未见任务验证。
- 数值轨迹匹配不覆盖零除提示、静态标题与动态结果的一致性、全部输入边界。桌面示例的模型文字还存在把读取与保存的确认要求混说的问题，需要语义修正。
- 桌面结果限于一个 Windows、Flash、JSON 流程；不是全部模型、权限模式、文件格式和跨平台矩阵。独立人工语义评判与完整产品验收仍未完成。
- 继续完成这些剩余功能与体验问题，并按三阶段计划推进。当前六项技术目标不能代替产品验收，CI 后置也不等于通过。
