- 独立 MiniApp 工具、预览及渲染器，受限 HTML/CSS/SVG、Canvas 与 Three.js 视图，Worker/QuickJS 隔离计算及资源预算；普通聊天通过公共输出接口接入。
- 可编辑动态列表、按键与拖动、播放与单步、三维对象选择、镜头及嵌套组合；参数预设、保存、检查点恢复与后续追问使用已确认状态。
- 候选修订、受限任务进度迁移、组件与小程序互转；参数核对、取消和重复确认保留来源与分支边界。
- 登记动作复用会话权限：读取参数后明确采用，结果报告只新建；新增输入顺序确认、严格数值比较、自然表达评估及原始任务重放。
- 桌面测试夹具只编译一次，避免开发监听重启；新增 Windows 原生窗口场景，仍在调试恢复路径。
