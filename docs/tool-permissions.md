# 工具执行审批

设置 → 对话与任务中的「工具执行审批」默认开启，控制输入框权限菜单与实际审批。菜单支持「请求批准」「帮我批准」「完全访问」，兼容旧的严格审批模式。首次安装仍使用完全访问，已有聊天与默认模式保留原先选择。

关闭开关会隐藏权限菜单与审核状态，停用人工及模型审批，正在等待的工具审批会释放；普通业务提问仍需回答。重新开启恢复原有模式，不会改写聊天权限或记住的默认模式。已执行的操作不会被撤销。

开关保存在 agent 目录的 `piora/tool-approval.json`。每次工具调用读取开关；修改后使进行中的审核失效，旧审核结果不能覆盖新设置。扩展自身阻止、远程会话边界及浏览器密码保护继续生效。浏览器登录仍支持自动继续。
