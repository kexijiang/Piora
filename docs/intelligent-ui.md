## 使用

在设置 → 实验功能（Beta Features）开启 Intelligent UI。默认关闭，选择保存在 Pi 数据目录的 `piora/beta-features.json` 中。可请求「做一个人数可调的采购清单」「用滑块比较不同预算」或「做一个可修改人数和金额的分账器」。模型按需要调用 `piora_render_ui`，普通问题仍用文字回答。

控件在本地即时计算，不为每次调整请求模型。参数保存到服务端后显示「已保存」，继续发送、编辑历史、分叉或导航前会等待待保存参数；保存失败会保留本地修改并提示重试或解决冲突。勾选和选择可通过受限条件表达式参与计算。

开关对智能体在下一轮开始时生效，已运行的一轮保留原能力。关闭时前端立即显示文字快照，不再加载交互渲染器。参数未保存成功时可以重试，也可以明确选择关闭并在本机保留未保存参数；重新开启后恢复草稿并重新核对服务端版本。已保存状态不会因关闭开关而删除。

## 模块边界

- 普通对话只识别 `answerOutput` 公共内容封套、快照和通用待保存接口。过程折叠不会隐藏已识别的回答输出。
- 独立目录 `lib/intelligent-ui/` 管理规格校验、计算和状态，`components/intelligent-ui/` 管理渲染和客户端状态，独立扩展提供模型工具。
- `AnswerOutput` 仅在开启功能且有有效输出时懒加载渲染器；关闭、历史只读视图、加载失败和未知版本保留文本。
- 运行时仍共享原有 AgentSession、SSE、消息发送、权限和持久化边界，没有第二套模型客户端或聊天数据库。加载计划在执行扩展模块前过滤关闭的功能；存量会话在新轮次重新加载能力，避免缓存旧工具。

## 协议与交互

工具接收 `id`、`title`、`nodes`。宿主附加协议版本和递增的界面版本。支持 `text`、`number`、`slider`、`select`、`checkbox`、`metric`、`table` 和 `barChart`；稳定 ID 用于恢复和版本衔接。

值可以是常量、控件引用或限定的计算表达式。支持加减乘除、取整、最小最大、严格相等和条件选择。表达式经过数量、深度、引用、数据类型与数值范围校验，不使用 `eval`，不接受 HTML、JavaScript、URL、任意组件名或任意动作。

每次工具调用提交一份完整、经过校验的界面。完成的工具结果可在最终文字回答前操作；模型可继续提交同一界面 ID 的下一版。此版未实现工具参数 token 级别的局部节点渲染，也不渲染未校验的半截 JSON。

修改参数只保存数据。需要查询、文件或网络操作时继续通过普通对话与已有工具权限机制执行；没有能绕过权限的界面执行接口。

## 状态、分支与恢复

最终工具结果在会话中保存完整规格和文字快照。交互状态保存于 Pi 数据目录 `piora/intelligent-ui/`，文件名由会话 ID 哈希生成，不能由模型指定路径。

保存采用文件锁、界面版本和乐观并发检查。状态按会话、界面和分支节点关联；使用活动 SessionManager 读取实际选中分支。回到祖先修改参数时，已有子分支冻结原值，新建分支继承新值。分叉与复制仅拷贝所保留历史的状态，后续互不影响。版本变化保留类型、范围兼容的参数；不兼容参数使用新规格默认值。

虚拟列表卸载不会丢失待保存状态。客户端保留有限的可回收缓存，未确认的参数在本机恢复记录中保留；重载后遇到分支或版本不一致，必须明确解决冲突。后续模型请求只获得当前分支有限的已保存快照，并被标记为任务数据，不是指令或工具授权。

HTML 导出保留原始工具快照，并附加当前分支已保存参数；离线导出不运行交互控件。普通历史只读视图保留当时的输出快照。删除到回收站期间保留参数以便恢复，永久清理时清理对应服务端参数。

## 范围与验证

第一阶段聚焦「生成 → 本地操作 → 保存 → 追问」闭环。任意代码小程序、动画游戏、复杂模拟、自定义网络动作和供应商参数流式适配属于后续阶段。

回归覆盖协议限制、本地计算、保存冲突、分支与分叉、真实 SDK 扩展注册及开关生效、关闭后的快照、普通聊天路径，以及浏览器控件、焦点、刷新、窄屏和中英文。浏览器时延来自本地固定数据测试，不能代表真实模型生成速度。上线前仍需在实际模型和桌面发行包中验收；本地不构建 Next 生产包或发布包。具体命令、结果、失败复测和未覆盖范围见 [首次验证记录](verification/intelligent-ui-2026-10-28.md) 和 [同步 beta.44 验证记录](verification/intelligent-ui-rebase-2026-10-28.md)。
